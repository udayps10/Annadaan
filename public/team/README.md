# Team Photos Directory

This directory contains the team member photos for the "About the Team" section.

## Required Images

Please add the following images to this directory:

### Group Photo (Hero Banner)
- **Filename:** `group-photo.jpg`
- **Dimensions:** 1920x1080 (landscape orientation)
- **Description:** Full team photo for the hero banner section
- **Format:** JPG or PNG

### Individual Team Members
- **Filename:** `member1.jpg` through `member5.jpg`
- **Dimensions:** 800x800 (square/portrait orientation)
- **Description:** Individual portraits of each team member
- **Format:** JPG or PNG

### Mentor Photo
- **Filename:** `mentor.jpg`
- **Dimensions:** 800x800 (square/portrait orientation)
- **Description:** Portrait photo of the mentor
- **Format:** JPG or PNG

## Image Guidelines

- Use high-quality images (minimum resolution as specified above)
- Ensure consistent lighting and background style across team member photos
- Images should be optimized for web (compressed but maintaining quality)
- Preferred format: JPG for photos
- All faces should be clearly visible
- Professional yet approachable tone
